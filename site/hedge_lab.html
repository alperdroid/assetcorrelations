What the models can and cannot forecast

Study 5 pitted seven forecasting approaches against simple benchmarks, month by month since 1990, using only data available at the time. Bars show each model's out-of-sample R²: positive means it beat the benchmark (historical average for returns, last month's value for risk). A target passes only if a model beats the benchmark after correcting for the number of tests.

Gold's one-month "pass" comes from the price series, not the market: World Bank gold prices are monthly averages, which makes each month's change partly predictable from the last (a model using only gold's previous month did even better). The effect cannot be traded, so the forecast does not use it.

Method

How the numbers are made

Data

  • US market, T-bills and 12 industries: Kenneth R. French Data Library
  • 10-year Treasury total return built from FRED DGS10
  • Gold: World Bank monthly averages (datahub mirror); averaging smooths gold's volatility
  • Regimes: CPI, unemployment and the Philadelphia Fed survey from FRED, with publication lags

Simulation

  • Monthly rebalancing to target weights; costs charged on turnover
  • Sharpe ratio = average excess return over T-bills ÷ volatility, annualised
  • Forecast: stationary block bootstrap (average block 12 months), 2,000 paths, fixed seed
  • Sector names approximate Ken French SIC-based industries

Evidence

  • Four studies, each specified before its results were seen; p-values adjusted for multiple tests
  • Full code and findings: alperdroid/assetcorrelations
